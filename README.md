### 3. SPHY Analytics Dashboard (`sphy_cvpk_analytics.py`)

The visual and analytical suite was built to be lightweight and universal, requiring only standard Python math libraries.

```text

numpy>=1.21.0
matplotlib>=3.4.0

```

To install the requirements, run:

```bash
pip install -r requirements.txt

```
